Claudefuscator

Restores Claudefuscator tokens to their real values in the claude.ai page. Everything below is stored in chrome.storage.local on this machine only — it is not synced to your Google account and it is never transmitted.

Key

Must be byte-for-byte the same value you entered on the Claude Code side. Enter it here independently; do not paste it into a chat, a commit, or a file in the repo.

Identifier list

Paste the contents of your claudefuscator.local.json. The extension recomputes the same tokens from these values, which is how it restores them without any mapping ever being transmitted.

This stores your real identifier values in the Chrome profile on this machine. Values not in this list can still be tokenized by a pattern on the Claude Code side, but cannot be restored here — only in the terminal.

Display

Marks restored values on the page with a faint wash and a dotted underline, so you can see at a glance what came back from a token and what was always there. Painted with the CSS Custom Highlight API, so nothing in the page's structure changes.

Toggle on any claude.ai tab with Alt+Shift+H.

Test

Derives the tokens for your list entries locally, so you can check they match what the Claude Code side produced for the same key. Real values are shown here because they are already on this page.
